# قواعد XP و استریک

نسخه: ۱.۰ (هم‌راستا با کد فعلی)  
XP شاخص رشد است؛ Credits هنوز پیاده نشده و جدا خواهد ماند.

## رویدادهای XP

| رویداد | مقدار پیش‌فرض | reason (ایدمپوتنت) |
|--------|----------------|---------------------|
| خواندن KB هفته | ۵ | `kb:read:week:{n}` |
| تحویل به‌موقع تکلیف | `assignment.xp_reward` (معمولاً ۲۰) | `submit:assignment:{id}` |
| تنظیم دستی ادمین (+) | مقدار فرم | `admin:adjust:+:{timestamp}` |
| جریمه ادمین (−) | مقدار فرم | `admin:adjust:-:{timestamp}` |

## ایدمپوتنسی

`award(user_id, amount, reason)` اگر قبلاً همان `reason` برای همان کاربر در `XPLog` باشد، XP اضافه نمی‌کند.

## استریک

- بر اساس روز فعال با فعالیت آموزشی معنادار (ثبت XPLog) به‌روز می‌شود.
- ورود صرف به‌تنهایی استریک نمی‌سازد.
- منطقهٔ زمانی محاسبات: UTC (مطابق سرویس streak).

## لیدربورد

- فقط کاربران غیر ادمین و فعال (`is_active=True`)
- مرتب‌سازی بر اساس مجموع XP نزولی
- رتبه تنها معیار موفقیت نیست؛ پیشرفت شخصی روی داشبورد نمایش داده می‌شود.

## Resubmit تکلیف

به‌روزرسانی لینک GitHub تا قبل از نمره‌دهی مجاز است و XP مجدد نمی‌دهد.
