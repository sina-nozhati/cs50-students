## دوره چیست؟

طبق [سیلابس رسمی](https://cs50.harvard.edu/x/syllabus/)، CS50x مقدمه‌ای بر «تلاش‌های فکری علوم کامپیوتر و هنر برنامه‌نویسی» است. دوره یاد می‌دهد چطور الگوریتمی فکر کنی و مسئله‌ها را کارآمد حل کنی. زبان‌های دوره C، Python و SQL به‌علاوهٔ HTML، CSS و JavaScript هستند. دوره با یک پروژهٔ نهایی تمام می‌شود و برای افراد «با یا بدون تجربهٔ قبلی برنامه‌نویسی» طراحی شده است.

## رویکرد CS50x Anzali

- **یادگیری مقدم بر امتیاز** (سند مادر PRD، بند ۲.۴): XP بازخورد است، نه هدف.
- هر هفته در این ساختار: نمای کلی ← یادداشت‌های فارسی هر بخش ← درس‌های کوتاه با واحدهای سنجش‌پذیر ← فلش‌کارت و مرور فاصله‌دار ← آزمون تسلط ← پرابلم‌ست رسمی با راهنمای آموزشی بدون راه‌حل.
- **صداقت علمی:** طبق سیاست رسمی CS50، در پرابلم‌ست‌ها فقط CS50 Duck مجاز است. راهنماهای این بسته هرگز راه‌حل نمی‌دهند.
