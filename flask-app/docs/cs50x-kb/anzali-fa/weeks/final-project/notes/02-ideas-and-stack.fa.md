# انتخاب ایده و ابزار

> **منبع رسمی:** بخش «Ideas» از [صفحهٔ پروژهٔ نهایی CS50x 2026](https://cs50.harvard.edu/x/2026/project/#ideas). این صفحه بازنویسی وفادار فارسی است، نه ترجمهٔ کلمه‌به‌کلمه. الزام‌های رسمی به انگلیسی و کلمه‌به‌کلمه نقل شده‌اند و مطالب **تألیفی** جدا برچسب خورده‌اند.

## چرا این بخش مهم است

بیشتر وقتی که در پروژهٔ نهایی هدر می‌رود، پیش از نوشتن اولین سطر کد هدر می‌رود: ایده‌ای که خیلی بزرگ است، یا ابزاری که هنوز بلدش نیستی. انتخاب خوب ایده و ابزار، نیمی از کار است.

## ایده‌های رسمی

صفحهٔ رسمی این نمونه‌ها را پیشنهاد می‌کند:

- برنامهٔ تحت وب با JavaScript، Python و SQL
- برنامهٔ iOS با Swift
- بازی با Lua و LÖVE
- برنامهٔ Android با Java
- افزونهٔ Chrome با JavaScript
- برنامهٔ خط فرمان با C
- برنامه‌ای مبتنی بر سخت‌افزار که در آن دستگاهی را برنامه‌نویسی می‌کنی
- …

فهرست با «…» تمام می‌شود: این‌ها فقط نمونه‌اند و ایده محدود به آن‌ها نیست.

## انتخاب ایده

> [!TIP]
> **تألیفی: سه پرسش برای سنجیدن ایده**
> ۱. آیا خودت (یا کسی که می‌شناسی) واقعاً این مسئله را دارد؟ صفحهٔ رسمی از «حل یک مسئلهٔ واقعی» و «اثر بر جامعه» نام می‌برد.
> ۲. آیا می‌توانی نسخهٔ کوچکی از آن را در چند هفته کامل کنی و بعد بزرگش کنی؟
> ۳. آیا از درس‌های این دوره بهره می‌گیرد؟ این تنها شرط رسمی دربارهٔ ماهیت پروژه است.

## انتخاب ابزار (`stack`)

- **مجموعهٔ فناوری** (`stack`) یعنی زبان‌ها، کتابخانه‌ها و ابزارهایی که پروژه با آن‌ها ساخته می‌شود.
- صفحهٔ رسمی هیچ زبانی را اجباری نمی‌کند: «هر زبانی».

> [!NOTE]
> **تألیفی: از آنچه بلدی شروع کن**
> در این درس C (هفته‌های ۱ تا ۵)، Python (هفتهٔ ۶)، SQL (هفتهٔ ۷)، HTML، CSS و JavaScript (هفتهٔ ۸) و Flask (هفتهٔ ۹) را دیدی. اولین نمونهٔ رسمی، یعنی برنامهٔ تحت وب با JavaScript، Python و SQL، تقریباً همهٔ این‌ها را کنار هم می‌گذارد. اگر ابزاری را انتخاب می‌کنی که در درس نبوده (مثلاً Swift یا LÖVE)، وقت یادگرفتنش را هم در برنامه‌ات بگذار؛ پرسش رسمی «چه مهارت‌های تازه‌ای لازم داری؟» دقیقاً همین است.

> [!WARNING]
> **تألیفی: ایده‌ات را از دیگران نگیر**
> ایده گرفتن از فهرست بالا یا از نمایشگاه پروژه‌ها برای الهام بی‌اشکال است، اما رونویسی پروژهٔ کس دیگری نقض صداقت تحصیلی است. یادداشت ۴ را ببین.
