### Communities

So that students can connect with classmates via platforms on which they’re already spending (too much!) time, CS50 has official communities on [Discord](https://cs50.harvard.edu/x/communities/#discord), [Ed](https://cs50.harvard.edu/x/communities/#ed), [Facebook](https://cs50.harvard.edu/x/communities/#facebook), [Gitter](https://cs50.harvard.edu/x/communities/#gitter), [Instagram](https://cs50.harvard.edu/x/communities/#instagram), [LinkedIn](https://cs50.harvard.edu/x/communities/#linkedin), [Quora](https://cs50.harvard.edu/x/communities/#quora), [Reddit](https://cs50.harvard.edu/x/communities/#reddit), [Slack](https://cs50.harvard.edu/x/communities/#slack), [Snapchat](https://cs50.harvard.edu/x/communities/#snapchat), [SoundCloud](https://cs50.harvard.edu/x/communities/#soundcloud), [TikTok](https://cs50.harvard.edu/x/communities/#tiktok), [X](https://cs50.harvard.edu/x/communities/#x), and [YouTube](https://cs50.harvard.edu/x/communities/#youtube).

If not already a user of any of those, allow us to suggest that you start with [Ed](https://cs50.harvard.edu/x/communities/#ed)!
