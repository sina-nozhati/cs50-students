### Practice Problems

If you want some extra practice **after** completing the problem set for a week, you can choose from these practice problems. These are **not** warm-up exercises; in many cases, they can be harder than the problem set problems themselves!

All of these problems are entirely optional and cannot be submitted!

<a id="after-week-1"></a>

##### After [Week 1](https://cs50.harvard.edu/x/weeks/1/)

* [Debug](https://cs50.harvard.edu/x/practice/debug/), for becoming familiar with C syntax and debugging programs.
* [Half](https://cs50.harvard.edu/x/practice/half/), for practice creating a function.
* [Prime](https://cs50.harvard.edu/x/practice/prime/), for practice using `for` loops.

<a id="after-week-2"></a>

##### After [Week 2](https://cs50.harvard.edu/x/weeks/2/)

* [Hours](https://cs50.harvard.edu/x/practice/hours/), for practice with arrays, passing arrays as parameters to a function, integer division and type casting.
* [N0 V0w3ls](https://cs50.harvard.edu/x/practice/no-vowels/), for practice with `string`s, command-line arguments, and writing an entire program from scratch.
* [Password](https://cs50.harvard.edu/x/practice/password/), for practice iterating through a `string`, using the `ctype.h` library, and using Boolean variables.

<a id="after-week-3"></a>

##### After [Week 3](https://cs50.harvard.edu/x/weeks/3/)

* [Recursive `atoi`](https://cs50.harvard.edu/x/practice/atoi/), for practice creating recursive functions.
* [Average Temperatures](https://cs50.harvard.edu/x/practice/temps/), for practice working with `struct`s and sorting algorithms.
* [Max](https://cs50.harvard.edu/x/practice/max/), for practice passing arrays to functions and finding maximum values.
* [Snackbar](https://cs50.harvard.edu/x/practice/snackbar/), for practice using `struct`s and writing a linear search algorithm.

<a id="after-week-4"></a>

##### After [Week 4](https://cs50.harvard.edu/x/weeks/4/)

* [Bottom Up](https://cs50.harvard.edu/x/practice/bottomup/), for practice working with images and metadata.
* [License](https://cs50.harvard.edu/x/practice/license/), for practice working with files and file pointers.

<a id="after-week-5"></a>

##### After [Week 5](https://cs50.harvard.edu/x/weeks/5/)

* [Trie](https://cs50.harvard.edu/x/practice/trie/), for introducing more complex data structures and working with tries.

<a id="after-week-6"></a>

##### After [Week 6](https://cs50.harvard.edu/x/weeks/6/)

* [Bank](https://cs50.harvard.edu/x/practice/bank/), from CS50’s Introduction to Programming with Python, for practice with `str`s.
* [Frank, Ian and Glen’s Letters](https://cs50.harvard.edu/x/practice/figlet/), from CS50’s Introduction to Programming with Python, for practice with libraries and command-line arguments.
* [Jar](https://cs50.harvard.edu/x/practice/jar/), from CS50’s Introduction to Programming with Python, for an introduction to classes and object-oriented programming, if feeling more comfortable.
* [Seven Day Average](https://cs50.harvard.edu/x/practice/seven-day-average/), for practice with requests, `dict`s, and data, if feeling more comfortable.
* [Taqueria](https://cs50.harvard.edu/x/practice/taqueria/), from CS50’s Introduction to Programming with Python, for practice with `dict`s and `try-except` blocks.

<a id="after-week-7"></a>

##### After [Week 7](https://cs50.harvard.edu/x/weeks/7/)

* [Favorites](https://cs50.harvard.edu/x/practice/favorites/) for practice using `SELECT` and `UPDATE` keywords.
* [Hall of Prophecy](https://cs50.harvard.edu/x/practice/prophecy/) for practice refactoring a database, using `CREATE`.

<a id="after-week-8"></a>

##### After [Week 8](https://cs50.harvard.edu/x/weeks/8/)

* [Radio Shack Redo](https://cs50.harvard.edu/x/practice/redo/), for practice with Bootstrap (and some web development history!)

<a id="after-week-9"></a>

##### After [Week 9](https://cs50.harvard.edu/x/weeks/9/)

* [Hello, Flask](https://cs50.harvard.edu/x/practice/helloflask/), for practice writing a Flask application from scratch.
